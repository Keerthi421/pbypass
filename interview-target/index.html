Optimal Hash Map Approach

Store each previously seen value and its index in a hash map. For every element, check whether target - value already exists.

map = {}
for i, value in enumerate(nums):
    complement = target - value
    if complement in map:
        return [map[complement], i]
    map[value] = i
TimeO(n)
SpaceO(n)
